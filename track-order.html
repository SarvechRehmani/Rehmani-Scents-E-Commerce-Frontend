        About Tracking

        Orders are stored only in the browser where the checkout was completed. If you placed the order on a different device, cleared your browser data, or used a private browsing window, the order will not be available here. This is a demo storefront — no server stores your orders.
        The five statuses shown in the timeline are: Order Placed, Processing, Dispatched, Out for Delivery and Delivered. These are illustrative stages for a demo tracker — they do not reflect any real courier movement or logistics system.
        Because this storefront has no backend, orders cannot be modified after submission. In a live store, you would normally contact support as early as possible to request an address change before dispatch.
        No. This is a frontend-only demo. There is no integration with any courier or logistics provider. The timeline is generated locally from the order data saved in your browser.
